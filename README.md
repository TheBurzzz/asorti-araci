# Asorti Aracı

Gerber AccuMark ile çalışan asorti / pastal planlama uygulaması.

## Kurulum
1. Sağ üstteki yeşil **Code** düğmesi → **Download ZIP**.
2. ZIP'i bir klasöre çıkar.
3. **Kurulum.bat** dosyasına çift tıkla; sihirbaz adım adım kurar.

Gerber AccuMark kurulu olmayan bilgisayarda sihirbaz "sadece asorti" kurar
(asorti hesabı, Excel'e kaydetme, yazdırma çalışır; Gerber'e gönderme kapalı olur).

## Güncelleme
Uygulama açıldığında yeni sürüm varsa üst çubukta **Güncelle** düğmesi çıkar.
Çalışma sayfaları ve ayarlar korunur.

Sürüm bilgisi: `AsortiAraci/surum.json`
